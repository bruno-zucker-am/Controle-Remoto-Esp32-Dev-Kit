# Controle-Remoto-Esp32-Dev-Kit
Simulação de controle remoto infravermelho com ESP32 DevKit no Wokwi. Ao receber um comando (IRremote), o código em C++ mostra o valor HEX no Monitor Serial, pisca um LED e mede a distância com sensor ultrassônico HC-SR04, com divisor de tensão no ECHO. Desenvolvida como parte de um portfólio prático de sistemas embarcados.
